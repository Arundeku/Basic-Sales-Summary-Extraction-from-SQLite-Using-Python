Basic Sales Summary Extraction from SQLite Using Python

## 📌 Objective

The goal of this task is to demonstrate the ability to extract, analyze, and visualize sales data stored in an SQLite database using Python. This includes writing and executing SQL queries, handling data with pandas, and visualizing the results using matplotlib.

This task is part of a broader learning module focused on integrating Python with databases for real-world data analysis applications.

---

## 📂 Files Included

- `sales_data.db` – SQLite database file (auto-generated by script if not present).
- `Basic Sales Summary Extraction from SQLite Using Python.ipynb` – Main Python script that:
  - Creates a sample sales table (if it doesn’t exist).
  - Inserts mock data for testing.
  - Executes a SQL query to summarize sales by product.
  - Displays the result using pandas and matplotlib.
- `sales_chart.png` – Bar chart image output (generated when script is run).
- `README.md` – This documentation file.

---

## 🛠️ Tools & Technologies Used

- **Python 3.7+**
- **SQLite3** (built-in with Python)
- **pandas** for data manipulation
- **matplotlib** for data visualization

---

## 🧾 Description of the Task

This task simulates a basic sales reporting system where sales data (product name, quantity sold, and price) is stored in a local database. The user is expected to:

1. Create a `sales` table in SQLite (if not already present).
2. Insert example data into the table.
3. Run an SQL query to compute:
   - Total quantity sold for each product.
   - Total revenue generated by each product.
4. Display the summarized result in tabular form (using pandas).
5. Plot a bar chart of revenue by product (using matplotlib).
